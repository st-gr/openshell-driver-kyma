# openshell-driver-kyma

A Rust implementation of the [OpenShell](https://github.com/NVIDIA/OpenShell)
`ComputeDriver` gRPC contract for SAP BTP Kyma clusters. Provisions agent
sandboxes as `agents.x-k8s.io/v1alpha1/Sandbox` CRDs.

**Status:** Phase 1 — under active development.
